# Portfolio Site

A personal portfolio website designed to showcase projects, skills, experience, and contact information in a clean and modern layout.

## Overview

This project is a lightweight static website built with standard web technologies. It is intended to serve as a personal landing page for professional branding and portfolio presentation.

## Project Structure

- `index.html` — main portfolio page containing the website content and structure

## Features

- Clean personal portfolio layout
- Responsive single-page design
- Easy to customize for personal branding
- No framework or build step required

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/GBaitali/Portfolio-Site.git

  2.  Open index.html in your browser or use Live Server in VS Code.

## Technologies Used ##
- HTML5
- CSS3
- JavaScript
- Static web hosting(Github Pages)
